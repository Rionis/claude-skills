# Шаблон: одностраничный сайт подрядчика с калькулятором

Шаблон для сайтов вида «услуга + онлайн-калькулятор цены + заявка»: эпоксидные полы, кровля, покраска, клининг, ландшафт и т.п.
Он собран из блоков. Никакой сборки, фреймворков и CMS: файлы правятся в обычном блокноте (Notepad, Notepad++, VS Code) и
выкладываются на любой статический хостинг.

## Файлы

| Файл | Что внутри | Когда править |
|------|-----------|---------------|
| `index.html` | Все блоки страницы, отмеченные комментариями `<!-- БЛОК: ... -->` | Тексты, порядок блоков, добавить или убрать блок |
| `config.js` | Компания, контакты, **цены и опции калькулятора**, адрес отправки формы | Под каждого нового клиента |
| `styles.css` | Тема в `:root` (цвета, шрифт, радиусы), затем стили блоков | Цвета бренда |
| `app.js` | Логика калькулятора, формы и меню | Обычно не нужно |
| `privacy.html` | Заготовка политики конфиденциальности | Обязательно заменить текст |
| `_headers` | HTTP-заголовки безопасности (Netlify, Cloudflare Pages) | Когда добавляете внешние сервисы |

## Блоки (index.html)

1. **Шапка и навигация**: логотип, меню-якоря, кнопка «Заявка»; на мобильных меню сворачивается.
2. **Hero**: главный оффер, две CTA («Рассчитать», «Позвонить»), полоса доверия (объекты, рейтинг, гарантия).
3. **Услуги / Инфо**: карточки услуг.
4. **Калькулятор `#calc`**: площадь (длина × ширина или сразу площадь), тип покрытия, помещение, состояние основания, доп. опции → диапазон цены «от–до».
5. **Процесс**: 3–5 шагов работы.
6. **Галерея**: фото работ.
7. **Отзывы**.
8. **О компании**: лицензия, страховка, гарантия.
9. **FAQ** на нативных `<details>`, без JS.
10. **Контакты / форма заявки** с подставленным расчётом, honeypot и согласием на обработку данных.
11. **Подвал** + липкая кнопка звонка на мобильных.

**Добавить блок:** скопируйте участок от одного `<!-- ===== БЛОК` до следующего, поменяйте `id` и добавьте ссылку в `<nav>`.
**Убрать блок:** удалите участок целиком и его пункт в меню.

## Как устроен калькулятор

```
площадь = (длина × ширина) или «площадь»
множитель = помещение.k × состояние.k
от = площадь × система.min × множитель + доп.опции
до = площадь × система.max × множитель + доп.опции
итог = max(от, minJobPrice) … max(до, minJobPrice)
```

- Цена всегда показывается **диапазоном** с дисклеймером, а не одной цифрой: точную сумму называют после замера.
- `minArea`/`maxArea` отсекают ошибки ввода, `minJobPrice` задаёт минимальный заказ.
- Кнопка «Получить точную цену» переносит расчёт в форму: менеджер видит, что клиент насчитал.
- Под другую нишу правится только `config.js`: например, для кровли `systems` превращаются в материалы, `conditions` в уклон крыши.

## Форма заявки

- `config.js → form.endpoint` принимает HTTPS-адрес обработчика (Formspree, Getform, свой сервер, webhook n8n/Make/Zapier).
- Если поле пустое, открывается почтовый клиент (mailto). Это годится для старта, но часть заявок так теряется.
- **После указания endpoint добавьте его домен в CSP** в `index.html` и `_headers`: `connect-src 'self' https://formspree.io`.

## Безопасность: что встроено

| Риск | Защита в шаблоне |
|------|------------------|
| XSS | Данные выводятся только через `textContent`/`createElement`, нет `innerHTML` и inline-обработчиков |
| Внедрение чужих скриптов | CSP `script-src 'self'`; внешние скрипты подключаются только явным изменением CSP |
| Clickjacking | `frame-ancestors 'none'` и `X-Frame-Options: DENY` (в `_headers`) |
| Спам-боты | Скрытое поле-ловушка (honeypot) + минимальное время заполнения формы + ограничения длины полей |
| Двойная отправка | Флаг `sending` |
| Утечка данных по HTTP | Endpoint принимается только с `https://`, HSTS-заголовок |
| Абсурдный ввод в калькуляторе | Диапазоны `min/max`, проверка `isFinite`, отрицательные значения не принимаются |
| Лишние разрешения браузера | `Permissions-Policy` отключает камеру, микрофон, геолокацию, платежи |

### Что нужно сделать на сервере (шаблон этого не закрывает)

- **Валидировать и ограничивать частоту запросов на сервере.** Проверки на клиенте обходятся, honeypot отсекает только простых ботов. При спаме добавьте Cloudflare Turnstile или hCaptcha и разрешите их домен в CSP.
- Не хранить заявки в открытом доступе (Google Sheets по публичной ссылке и т.п.).
- Включить HTTPS и редирект с http.
- Сторонние счётчики (GA4, Meta Pixel) ставить только при наличии баннера согласия, если этого требует ваша юрисдикция (GDPR, CCPA), и добавлять их домены в CSP.
- Заменить текст `privacy.html` на юридически проверенный.

### Заголовки для Apache / Nginx

```apache
# .htaccess
Header set Content-Security-Policy "default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' data:; connect-src 'self'; form-action 'self' mailto:; base-uri 'self'; object-src 'none'; frame-ancestors 'none'"
Header set Strict-Transport-Security "max-age=31536000; includeSubDomains"
Header set X-Content-Type-Options "nosniff"
Header set Referrer-Policy "strict-origin-when-cross-origin"
```

```nginx
add_header Content-Security-Policy "default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' data:; connect-src 'self'; form-action 'self' mailto:; base-uri 'self'; object-src 'none'; frame-ancestors 'none'" always;
add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
add_header X-Content-Type-Options "nosniff" always;
add_header Referrer-Policy "strict-origin-when-cross-origin" always;
```

## Чек-лист запуска нового сайта

- [ ] `config.js`: компания, телефон, email, город
- [ ] `config.js`: цены, опции и минимальный заказ проверены у клиента на 2–3 реальных объектах
- [ ] `config.js`: `form.endpoint` указан, домен добавлен в CSP, тестовая заявка дошла
- [ ] `styles.css`: цвет бренда, контраст текста на кнопке ≥ 4.5:1
- [ ] `index.html`: `<title>`, `description`, `canonical`, `og:*` под клиента
- [ ] Фото в `img/` (webp, до 300 КБ, заполненный `alt`)
- [ ] Отзывы только реальные и с согласия клиентов
- [ ] `privacy.html` заменён
- [ ] Проверка на телефоне: нет горизонтальной прокрутки, кнопка звонка работает
- [ ] Консоль браузера без ошибок CSP

## Локальный просмотр

Можно открыть `index.html` двойным кликом. Для проверки как на хостинге:

```bash
python3 -m http.server 8000   # затем http://localhost:8000
```
